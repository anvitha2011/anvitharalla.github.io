## 📖 Overview

A clean, minimalist, editorial-styled portfolio designed to showcase software engineering projects, backend/full-stack proficiencies, academic background, and certifications. Built with pure HTML5, modern CSS3, and lightweight vanilla JavaScript for optimal performance and smooth animations.

---

## ✨ Features

- **Editorial & Modern Design**: Polished typography using *Cormorant Garamond* and *Outfit* fonts with subtle borders, warm neutrals, and dark ink accents.
- **Interactive Animations**: Smooth scroll reveals powered by the native `IntersectionObserver` API.
- **Projects Catalog**: Showcases full-stack and backend systems with tags for technologies, architecture, and live links to repositories:
  - *Employee Management System* (Java, Spring Boot, React, MySQL, Hibernate/JPA)
  - *REST API Development Suite* (Spring Boot, JUnit 5, Mockito, Postman, TDD)
  - *Student Management System* (Java, JDBC, MySQL, OOP)
  - *Movie Recommender*, *Fitness Tracker*, *Reading Helper*, *AI Quiz Generator*
- **Skills Matrix**: Categorized breakdown across Programming Languages, Backend, Frontend, Databases, Testing, and DevOps/Tools.
- **Education & Certifications**: Academic achievements (B.Tech CSE, PVPSIT) and verified credentials from NPTEL, Infosys Springboard, Stanford Online, and Step.
- **Responsive Layout**: Adapts gracefully across mobile screens, tablets, and desktop displays.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Modern CSS3 (CSS Variables, Flexbox, Grid, Keyframes)
- **Interactivity**: Vanilla JavaScript (`IntersectionObserver`)
- **Typography**: Google Fonts (`Cormorant Garamond`, `Outfit`)
- **Deployment**: GitHub Pages

## 💻 Local Development

To view or run the portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/anvitha2011/anvitharalla.github.io.git
   cd anvitharalla.github.io
   ```

2. **Open `index.html`:**
   - Double-click `index.html` to open it in your default web browser, or
   - Use VS Code Live Server or any lightweight local HTTP server:
     ```bash
     # Using Python
     python -m http.server 8000
     ```
   - Navigate to `http://localhost:8000` in your browser.
